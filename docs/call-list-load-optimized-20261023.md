# 通话列表批量归属查询优化及复测（2026-10-23）

## 修改

通话列表和客户详情通话列表改为按本页客户编号去重，一次读取客户编号与负责人 ID 两列；使用同一批结果计算归属状态和录音访问权限，不再逐条查询完整客户、头像、标签及协作集合。不使用跨请求缓存，因此客户流转后，下一次请求仍读取当前归属。

原销售保留已转出通话概要；电话、备注及录音权限继续按当前客户负责人控制。管理员权限、客户详情入口权限、音频和分析接口授权规则保持原有行为。公海和客户不存在时默认无录音访问权限。无需新增数据库结构。

共 12 个场景、7,989 次计时请求，错误数为 0。十万条通话、每页 100 条、30 并发场景：SQL 从 223 降到 4，减少约 98%；P95 从 2,040 降至 749 毫秒，降低约 63%；吞吐从 18.4 提升至 54.0 请求/秒。
