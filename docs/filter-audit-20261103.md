# 筛选检查与修复（2026-11-03）

本次修改在本地完成，未部署。浏览器使用测试数据和模拟接口验证，不代表线上数据库已验收。

## 已修复

- 坐席：人员、状态查询和重置生效。现有坐席数据均为离线，选择在线应显示空结果。
- 库存资源、服务库、过期 VIP 库：补充实际条件匹配、查询、重置和高级筛选；日期、数字范围包含边界，起止倒置会提示错误。
- 诚意资源：修复前后互相矛盾的公海判断，并接入资料、数值范围等条件。
- 客户库查询会读取 `/customers` 的所有分页再匹配，防止遗漏第一页以外的记录；切换账号会清除筛选数据缓存。
- 合同、流水、退费、业绩、用户表：对有实际值的字段接入查询、重置。此处仅筛选当前已加载记录，界面明确注明范围。
- 修复客户场景测试缺少 `visibleCustomerLibraryRows` 依赖的问题。

## 仍不可用，已在界面禁用

- 短信、卡券：当前页面没有接入实际记录来源。卡券原有的固定统计已去除。
- 旧合同页的会员 ID、审核状态，旧退费页的部分固定展示字段，以及流水等表中不存在的字段：不能基于写死的展示内容提供真实业务筛选。对应条件显示禁用及原因。

要启用这些条件，需要先接入相应的真实数据字段/接口。禁用只是避免误导，不代表业务功能已实现。

## 验证

- `scripts/test-library-filters.cjs`：浏览器操作各客户库查询、范围和重置、跨页读取、账号缓存隔离、坐席条件，以及五张旧表的可用字段。
- `scripts/test-render-browser.cjs`：页面切换、重复点击、公海场景、输入草稿和后台刷新稳定性。
- 客户场景 18 项、渲染稳定性 5 项、客户身份 7 项，以及标签、公海跟进次数、下一客户测试均通过。

本记录不是“全项目所有筛选均已可用”的结论；未接入数据的业务项仍需后续实现。
