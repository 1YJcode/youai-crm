# 公司知识审核

客户转写和确认跟进继续自动保存到客户私有档案，不自动公开。通话案例及成交复盘提交后状态为 PENDING，仅提交人和管理员可查看；管理员审核通过后公司可读并参与问答。支持退回原因、修改重新提交、下架，审核操作校验文章版本并保存审核账号和时间。管理员直接新增的通用知识视为管理员确认发布。

公司问答及增量索引均只使用 PUBLISHED。下架后业务端立即排除，远端副本由后台对账清理。原始客户资料继续执行客户归属权限。已发布案例的来源更新不会覆盖共享正文；有来源权限的用户在详情看到来源更新提示。

V47 保留已有知识的发布状态，避免升级造成现有知识不可用；新提交案例必须审核。历史内容仍需管理员人工复核。发布前执行数据库备份，随前后端部署运行迁移。

当前不自动生成新的 AI 候选草稿；销售通过现有整理入口提交独立正文，避免原始客户内容误公开。2026-11-03 已部署到本机 Docker 服务（前端 4173、后端 8500），V47 迁移成功，健康检查 UP，浏览器登录页可访问。数据库及旧镜像已备份。尚未执行登录后的浏览器交互验收或真实模型效果评估。
