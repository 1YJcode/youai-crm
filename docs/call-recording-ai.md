## 千问转写阶段（2026-10-24，代码已接入，尚未部署或真实调用）

本节覆盖下文旧版仅支持 OpenAI 的说明。当前优先完成上传后的原文转写，不包含角色判断和跟进模板填写。

- 在客户通话记录上传录音后，进入录音管理，勾选外部处理授权并点击“开始转写”。后台异步处理，成功后原文保存在对应录音，重开可以读取；替换录音仍清空旧转写。
- 服务端设置 `QWEN_ASR_API_KEY`，默认 `QWEN_ASR_MODEL=qwen3-asr-flash`，`QWEN_ASR_ENDPOINT=https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions`。不同地域或工作空间请使用控制台提供的匹配接口地址和密钥。Compose 已传入这些变量，修改后需要重建/重启后端使配置生效。不要把密钥填写到浏览器、提交 Git 或发送聊天。
- 配置千问后优先使用千问，不调用总结模型；无需 DeepSeek 凭证。未配置千问时保留旧服务兼容路径。
- 千问短音频接口单次最多五分钟，因此服务器使用 ffmpeg 将录音依次转为四分钟以内的单声道 16kHz WAV，通过 Base64 发送，不需要公开客户音频 URL 或另配 OSS。支持原始录音最多两小时，但上传仍受现有 20MB 限制，不能声称支持所有两小时文件。分段边界可能影响跨段句子识别，真实效果待录音验收。
- 分段范围是音频切片时间，不是模型返回的逐句时间戳。此版本不支持说话人分离、销售/客户身份判断、自动模板填写。静音或不完整响应按失败处理，不伪造原文。整个任务成功后才保存结果，失败可重试，重试会重新处理全部录音。
- Docker 镜像已有 ffmpeg；直接启动 Java 需安装 ffmpeg/ffprobe，必要时设置 `FFMPEG_PATH` / `FFPROBE_PATH`。最多两个并行任务，进程重启中断后最迟两小时可重试，尚非持久任务队列。
- 官方接口依据：https://help.aliyun.com/en/model-studio/qwen-asr-api-reference 。API Key、账号模型权限、余额/免费额度及真实转写质量需在服务器配置后验收。

## 已实现

- 通话列表的“录音管理”弹窗：上传、鉴权播放、分析状态、原始转写、AI 草稿及人工编辑确认。
- WAV、MP3、FLAC、OGG，单文件上限 20MB；WAV 解析和数据长度检查，其他格式目前只检查文件头。浏览器能否播放其他编码取决于浏览器支持。
- 音频保存在 MySQL，跟随数据库持久化与备份。迁移为 V28（录音）、V29（分析）、V30（人工确认）。重新上传替换该通话录音并清空原分析与审核内容。
- 上传、读取、分析和审核均检查客户当前负责人权限；管理员可访问。客户转移后旧负责人失去访问权限。
- 两个后台分析线程，无等待队列；繁忙时返回 429。状态持久化，超过十分钟的中断任务允许手动重试。外部请求不占用数据库事务。
- 录音版本和分析启动时间防止旧任务覆盖新录音；审核版本防止旧编辑窗口覆盖新确认内容。重新分析清除之前的审核状态。
- 原始转写、AI 草稿和人工确认结果分别保存，确认记录包含账号和时间。不会自动创建跟进任务或发送客户消息。
- 结果按纯文本展示；音频与分析响应禁止缓存，关闭弹窗或退出/切换账号释放播放器资源。

## 本地使用

2. 进入通话记录，点击“录音管理”，选择已获授权、与当前客户对应的录音并上传。

## 可选 AI 配置

当前适配器只支持 OpenAI 官方接口，不代表用户已选定该服务。服务端环境变量（`.env.example` 默认留空）：

- `RECORDING_AI_API_KEY`
- `RECORDING_AI_TRANSCRIPTION_MODEL`：需支持 JSON 转写的模型。
- `RECORDING_AI_SUMMARY_MODEL`：需支持 Responses 文本输出的模型。

流程为 `/v1/audio/transcriptions` 转写，再用 `/v1/responses` 整理。Responses 设置 `store=false`；不将此参数解释为供应商零保留承诺。请求有超时和响应大小限制，禁止跟随重定向。密钥仅在后端读取。

摘要要求区分客户需求、异议、销售承诺、约定事项与建议；事实附原话依据，未提及明确标注，不猜测说话人身份。当前未实现说话人分离和时间戳分段。

接口依据：
- https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create
- https://developers.openai.com/api/reference/python/resources/responses/methods/create
